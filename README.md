## 三件容易被忽略的事

**第一，2TB 是双向流量。** WePC 页面上写的是“2TB 双向流量”，上传和下载合并计算，实际可用的单向流量只有 1TB。按 3Mbps 码率算，一小时直播上行约 1.35GB，一天播三小时、一个月九十小时，大约 120GB，2TB 双向是够的。但如果你同时跑多路推流，或者做视频搬运（下载原片再上传，两头都扣），消耗会快得多。ByteVirt 的 1TB、远振的 2000GB 都是单向计，直接拿来比会算错。

**第二，流量用完之后怎么办，三家三种做法。** ByteVirt 全系超量后端口限速到 1Mbps，不停机也不额外扣费；远振是加购流量每 1TB 新台币 3000 元；WePC 同店马来西亚那档产品页明确写了“超流量限速 5M”，台湾这档页面没标。限速 1Mbps 和限速 5Mbps 是两个体验，加钱和限速是两种成本结构，买之前必须确认是哪一种。

**第三，退款不是标配。** 丽萨提供 48 小时不满意无条件退款；ByteVirt 的 Lite 系列按条款是 5%–10% 的循环账户余额退款，TW-ISP 系列明确标注不退款；远振直接写“不提供退费”，理由是 VPS 属高度可自定义环境。WePC 的公开页面里我没找到台湾线的退款条款，别默认它有。👉 [在 WePC 台湾方案页确认条款后再下单](https://wepc.au/aff.php?aff=300)，或者先开工单问清楚再付钱。
